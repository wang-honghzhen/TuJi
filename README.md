图记是一款面向个人知识整理的桌面应用，将关系画布、图文笔记和 AI 对话放在同一个工作空间。你可以在画布上梳理知识结构，在笔记中记录细节，再通过 AI 协助整理和修改内容。

## 主要功能

### 用画布整理知识

通过节点、关系和子图表达知识之间的联系。图文档可以在多个画布中复用，修改内容时同步更新，让同一份资料参与不同主题的整理。

### 与 AI 一起完善内容

通过对话让 AI 协助创建节点、整理内容和调整关系，在“AI 修改”栏查看待审核提交。支持聊天、探索与临时会话，可按自己的需要配置 AI 服务和模型。

### 自由书写图文笔记

保留清晰的页号，每一页都可以持续向下书写。使用 `Ctrl+V` 粘贴图片，支持拖动、缩放、裁剪、旋转、并排和重叠排列；插入图片时，上下文字会自动分开，图片区独占所在行。

通过嵌套目录归类笔记，在独立标签中阅读不同目录。顶部显示目录路径与目录内页号，底栏中央显示全局页号；退出后再次打开，可继续上次的阅读位置。

### 快速找到需要的信息

- 在当前画布搜索节点、子图与关系，并将视图定位到对应位置。
- 在图文档栏查找图文档和待审核提交。
- 按笔记正文或目录路径搜索，查看匹配页面的全局页号与目录内页号。

### 随时打开记录空间

通过桌面悬浮球快速打开笔记与临时会话。侧边页支持调整宽度和独立窗口，切换窗口时保留草稿与阅读位置。关闭主窗口后，图记可继续留在系统托盘中。

### 阅读文件与扫描资料

支持文本、Markdown、PDF、图片等附件，Windows 安装包内置简体中文与英文 OCR 模型，可在本地识别扫描资料中的文字。笔记关键词搜索目前以文字和目录路径为范围。

## 下载与开始使用

支持 **Windows 10 / 11，64 位**。

1. 打开 [最新版本下载页](https://github.com/wang-honghzhen/TuJi/releases/latest)，下载名称以 `win-x64-setup.exe` 结尾的安装包。
2. 运行安装程序，选择程序位置和独立的数据存储位置，完成后从桌面或开始菜单打开“图记”。
3. 首次打开时，按界面提示填写 AI 服务地址、模型名称和 API 密钥。
4. 新建画布开始整理知识，或打开“笔记”和“目录”记录、归类内容。

安装包已包含所需运行环境，可直接安装使用。更新内容见 [版本记录](https://github.com/wang-honghzhen/TuJi/releases)。

## 数据与使用说明

笔记、画布、聊天记录和附件保存在本机。升级沿用原数据位置，卸载默认保留数据；选择新的空数据文件夹会打开一套空白数据，原内容仍保留在原位置。

AI 服务由你自行配置。使用 AI 功能时，请求所需的内容会发送给所配置的服务；通过应用界面保存的 API 密钥在本机加密存储。图片与扫描文档的 OCR 识别在本地进行。

需要完全退出程序时，请使用系统托盘菜单中的“退出”。
