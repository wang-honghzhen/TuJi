图记是一款面向个人知识整理的桌面应用，将关系画布、图文笔记和 AI 对话放在同一个工作空间。你可以在画布上梳理知识结构，在笔记中记录细节，再通过 AI 协助整理和修改内容。

## 主要功能

### 用画布整理知识

子图像目录，可以同时放子图和节点。每个节点都有自己的名称、正文和稳定引用，移动到另一个目录后，已有连线仍指向同一节点。图文档可以在多个画布中复用，修改内容时同步更新。

在画布中按 1、2、3 分别进入二维、分层三维和球体嵌套视图，也可按 V 或 Shift + V 顺序切换。顶部工具栏的「跨子图边」和「子图内边」控制各自的显示，「收束跨子图边」在汇总线和原始关系之间切换。二维以卡片显示节点，跨子图关系淡显。多层级三维用圆点和旁边的名称显示节点。三个视图共用详情面板。单击选中，按住 Alt 悬停可预览，Alt 加单击可固定详情。选中节点或关系后也可点工具栏的「编辑」。左键拖动节点或子图边框可移动位置，右键菜单可创建对象。选中节点后可从连接点拖出关系，选中关系后可拖动端点重连。

三维中按住滚轮拖动可以平移，滚动滚轮可以缩放。拖动空白处或按住 Alt 加左键拖动可绕选中对象旋转。触控板也可用 Shift 加左拖平移。按 F 聚焦选中对象。三个视图都可按 Home 回到全图。在设置的「常用快捷键」中可查看完整操作。

画布默认全显示。按 4 查看最近一次单击对象的邻域，按 5 查看选中范围。两种模式下，选中子图都会临时展开它的所有层级，显示内部节点、内部边，以及进出这个子图的边。子图外只补上这些边的另一端和所属层级。显式设置的边显示开关和单组收束设置仍然生效。再次按同一数字键返回全显示，并恢复之前的折叠状态。切换二维、分层或球体视图会保留当前范围。悬停节点可高亮相连的边，悬停边可辨认两端节点。在三维中，悬停节点或边还能阅读名称和正文。

三个视图共用连接数配色。节点按相连的原始边计数，普通子图按穿过自身边界的原始边计数。0–2 条为青色，3–7 条为紫色，8 条及以上为蓝色。两个端点都在同一子图内时，这条边不计入这个子图，图文档始终使用金色。子图边框、目录和路径中的名称使用同一组颜色。跨子图汇总线从起点子图色渐变到终点子图色，两端分别跟随所属子图。展开后，原始边恢复节点端点配色和原来的线型。

在任一视图中，右键单击子图边框或内部空白处，选择「收起子图」即可隐藏其中的节点和嵌套子图。再次右键可展开。单击某个子图只选中该子图。

两个三维视图都会微调重叠节点的屏幕位置。球体嵌套视图用虚线表示收束的跨子图边，用实线表示子图内边。跨子图关系按两端子图和方向汇总，正反向分别显示。三个视图都会在线上标出原始边数。点击数字可展开这一组，右键单击一条已展开的跨子图边，选择「收起同一组的跨子图边」即可重新汇总。顶部的「收束跨子图边」可一次切换整张画布。

球体视图中，落在前方球壳背后的节点会淡化并收起名称，边只在被挡住的那一段淡化。旋转到无遮挡的角度即可阅读和点选。选中的节点、选中边及其端点保持清晰，便于持续追踪。

按住 Ctrl 依次选中两个节点，再点「追踪最短路径」，可查看沿箭头经过的原始关系、交换起止点或定位其中一段。关闭追踪可返回逐段定位前的视角。

旧画布从第 0 层开始，选中子图升降一层时，其节点和嵌套子图会随之移动，层高按画布保存。

创建边或打开边详情时，可勾选依赖关系。例如将“发布清单”连到“验收标准”，箭头表示发布清单依赖验收标准。在节点详情的“依赖”和“被依赖”列表可直接跳到关联节点，也可以问 AI “发布清单依赖什么”或“哪些节点依赖验收标准”。旧画布里的普通连线保留原意，也可以逐条标记为依赖。

在图文档侧栏导入文件，或右键导出指定图文档。导出包含该文档的全部下级内容及内部关系；导入创建独立副本，保留嵌套结构。

### 与 AI 一起完善内容

通过对话让 AI 协助创建节点、整理内容和调整关系，在右侧栏的“待审核提交”中查看修改。支持聊天、探索与临时会话，可按自己的需要配置 AI 服务和模型。

创建子会话时可以直接开始，也可以选取希望继承的聊天记录。在画布右下角点击“收起 AI 到右侧”，即可腾出画布空间。点击“画布 AI”标签可查看连续聊天记录并输入消息。右键标签或侧页，选择“还原聊天视图”可打开完整聊天。

使用 `Ctrl+左键` 将节点或边加入多选或移出多选。对子图使用 `Ctrl+左键` 单击边框。在画布空白处按住 Ctrl 单击可退出多选。右键选择“将选中对象添加到当前会话”，会将你手动选中的对象添加为一组。不同组可包含相同对象，点击输入框中的组标记可恢复该组选中状态。

“仅选中”会显示手选对象和已定位的 AI 引用。回看分段回复时，可点击定位按钮再次查看本段引用。在“邻域”中，单击节点或子图可将它居中并查看它的邻域，多选集合单独保留。跨子图边的两端标有各自所属的子图路径，省略号代表与另一端相同的上级路径。

### 自由书写图文笔记

保留清晰的页号，每一页都可以持续向下书写。使用 `Ctrl+V` 粘贴图片，支持拖动、缩放、裁剪、旋转、并排和重叠排列；插入图片时，上下文字会自动分开，图片区独占所在行。

双击图片查看详情，或右键复制、剪切、删除。复制和剪切保留当前裁剪、旋转效果，详情中可切换原图。设置页的“快捷键参考”列出各区域的按键和功能。

通过嵌套目录归类笔记，在独立标签中阅读不同目录。页面菜单支持将笔记迁移或复制到目录，并调整目录内的页面顺序。顶部显示当前页号，底栏显示分类信息；退出后再次打开，可继续上次的阅读位置。

### 快速找到需要的信息

- 在当前画布搜索节点、子图与关系，并将视图定位到对应位置。
- 在图文档栏查找图文档和待审核提交。
- 按笔记正文或目录路径搜索，查看匹配页面的全局页号与目录内页号。

### 随时打开记录空间

通过桌面悬浮球快速打开笔记与临时会话，未进入画布时也可右键创建极简会话。侧边页支持调整宽度和独立窗口，紧凑的斜边标签区分笔记与会话，切换窗口时保留草稿与阅读位置。关闭主窗口后，图记可继续留在系统托盘中。

### 阅读文件与扫描资料

支持文本、Markdown、PDF、图片等附件，Windows 安装包内置简体中文与英文 OCR 模型，可在本地识别扫描资料中的文字。笔记关键词搜索目前以文字和目录路径为范围。

随消息发送的截图会直接交给执行模型看图。之后在同一会话中也可以请 AI 再看先前的图片、放大局部或查看 PDF 的指定页。

## 下载与开始使用

支持 **Windows 10 / 11，64 位**。

1. 打开 [最新版本下载页](https://github.com/wang-honghzhen/TuJi/releases/latest)，下载名称以 `win-x64-setup.exe` 结尾的安装包。
2. 运行安装程序，选择程序位置和独立的数据存储位置，完成后从桌面或开始菜单打开“图记”。
3. 首次打开时，按界面提示填写 AI 服务地址、模型名称和 API 密钥。
4. 新建画布开始整理知识，或打开“笔记”和“目录”记录、归类内容。

安装包已包含所需运行环境，可直接安装使用。更新内容见 [版本记录](https://github.com/wang-honghzhen/TuJi/releases)。

## 数据与使用说明

笔记、画布、聊天记录和附件保存在本机。升级沿用原数据位置，卸载默认保留数据；选择新的空数据文件夹会打开一套空白数据，原内容仍保留在原位置。

AI 服务由你自行配置。使用 AI 功能时，请求所需的内容会发送给所配置的服务；通过应用界面保存的 API 密钥在本机加密存储。图片与扫描文档的 OCR 识别在本地进行。

需要完全退出程序时，请使用系统托盘菜单中的“退出”。

## 从源码运行

在 Windows 上安装 Node.js 24.13 或更高版本，进入项目目录后运行：

```powershell
npm ci
npm run dev:desktop
```

开发版默认使用项目内的 `.local/data`。运行 `npm run package:win` 可在 `release` 目录生成 Windows x64 安装包。

如需用当前源码打开已安装正式版的笔记，先运行正式版完成首次设置，再在项目目录执行以下命令创建“图记（工作区测试）”桌面快捷方式。该入口共用正式版数据，启动时会先请正在运行的实例保存并退出。

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/workspace-desktop.ps1 -CreateShortcut
```
